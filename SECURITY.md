# Security Policy

## Supported versions
Only the latest release receives fixes. StreamFusion updates itself, so please update before reporting.

## Reporting a vulnerability
Please **do not open a public issue** for a security problem.

Use GitHub's private reporting: **Security tab, then "Report a vulnerability"** on https://github.com/MilannSharma/StreamFusion/security/advisories/new

Include what you found, how to reproduce it and what the impact is. You will get a reply as soon as possible, and credit in the fix if you want it.

## Good to know
- StreamFusion runs a local server on `127.0.0.1` for the app. It is not meant to be exposed to a network.
- Phones are controlled through `adb`. Pair only phones and networks you trust.
- Logins you enter for AI tests are stored on your own PC and are not sent anywhere except to the AI provider you chose.
