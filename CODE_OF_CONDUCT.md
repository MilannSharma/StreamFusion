# Code of Conduct

## Our pledge
We want StreamFusion to be a friendly, harassment-free place for everyone, whatever their experience, background or identity.

## Expected behaviour
- Be kind, patient and respectful.
- Give and accept feedback on the work, not the person.
- Assume good intent and ask when something is unclear.

## Unacceptable behaviour
- Harassment, insults, discrimination or personal attacks.
- Trolling, spam or deliberately derailing discussions.
- Publishing someone else's private information.

## Enforcement
Maintainers may edit or remove comments, issues and pull requests that break these rules, and may block repeat offenders. To report a problem, open a private security advisory on this repository (Security tab) or contact the maintainer through their GitHub profile: https://github.com/MilannSharma

This Code of Conduct is adapted from the [Contributor Covenant](https://www.contributor-covenant.org), version 2.1.
